# V5：事件分段 SPARC + 位置 TED

版本：`event-sparc-position-ted-v5`。实现：`src/lib/trajectory-phase-sparc.ts`。日期：2026-09-23。

## 数据与人工标注边界

读取完整、裁剪前的 `observation.state` 中具名末端 XYZ、时间戳和夹爪数据。按时间戳估计真实采样间隔，连续有效段内重采样；遇到无效值、重复/逆序时间戳或明显时间缺口就断开。

遵照用户最后的约束，人工结论只作为独立浏览器记录保存。评分模块、离线核对脚本不接收、不导入人工标签；已移除运行中的人工参考范围校准、人工一致率和误报率计算。没有使用人工标签选参数或验证新结果。原有人工记录存储键和数据指纹保留。

## 1. 阶段边界

阶段由接触状态（有可靠字段时优先）、夹爪高低状态和持续运动状态决定。夹爪状态沿用 40%/60% 滞回和 0.2 秒持续判定；阶段端点共享一个样本，确保连续数据的每个时间间隔都有归属。

运动状态用 0.6 秒上下文的位置范围估计；不足 0.8 秒的内部静止间隙并入原运动段，因此不会每次出现速度波动就切段。高频振荡本身不会直接产生新的边界。这里的事件段是可变长度的代理阶段，不是抓取/搬运等语义的自动识别结果。

噪声估计取自一秒低速、低漂移片段：片段中位速度不超过全段 P90 速度的 10%，端点净漂移不超过片段空间范围的一半。每轴用二阶差分的 MAD 除以 `0.67448975 * sqrt(6)` 估计位置噪声，再合成各轴。至少两个候选片段才能返回估计值。

活动位移下限取 `max(8 * noiseEstimate, wholeExtent * 1e-4, numericalFloor)`。该值是固定工程规则和自动噪声估计，不是测量设备的真值标定。低于下限只表示没有足够运动信号，不给予低分或满分；估计失败会在详情中明确提示。慢速微小动作可能需要更可靠的传感器噪声标定。

## 2. 标准 SPARC

对每个可评分运动阶段按真实时间戳求 XYZ 速度模长，进行作者定义的幅度谱归一化与弧长积分：

- 归一化参考为非负速度谱 DC，等于谱最大值。
- FFT 补零至 `2^(ceil(log2(N)) + 4)`；补零仅增加频谱采样密度。
- 幅度阈值 0.05；截止上限 `min(10 Hz, 实际采样率 / 2)`。
- 截止频率取范围内最后一个达到幅度阈值的频点。
- 对归一化频率与归一化幅度求负弧长；没有对数谱或 Hann 窗。
- 主评分信号不做额外平滑，避免把真实抖动预先滤掉。

阶段至少 1 秒、15 个采样间隔。过短阶段不评分；已评分运动时长须覆盖候选运动时长的至少 80%，有效样本比例至少 80%，才生成相对总分。低运动信号与数据缺口不计入运动覆盖率分母，页面明确其含义。

文献：[2015 SPARC 定义](https://pmc.ncbi.nlm.nih.gov/articles/PMC4674971/#Sec4)、[事件分段与汇总](https://pmc.ncbi.nlm.nih.gov/articles/PMC4674971/#Sec5)、[作者代码](https://github.com/siva82kb/smoothness/blob/master/python/smoothness.py)。

## 3. TED 辅助与汇总

TED 使用相同的有效运动片段，每段只拟合一个端点约束三次 Bézier 包络。取消由残差不断增加拟合区域的做法，避免较差的运动获得更多拟合自由度。DTW 累计距离除以实际对齐路径长度，再由阶段空间范围归一化。

这是 XYZ 位置 TED 的项目近似，不是完整接触感知位姿 TED。合法复杂转弯可能增加残差，因此几何指标只提供有限辅助。

一个 episode 在同一接触/夹爪状态中的多个运动阶段，按时长加权得到该状态的 SPARC 和 TED。各 episode 的同状态汇总值互相比排名，每条 episode 在一个状态中只贡献一个值。至少 3 条可评分的同状态 episode 才给百分位。

百分位采用中秩：`(严格更差数量 + 同分数量 / 2) / N`。SPARC 越大越好，TED 越小越好。不同状态的百分位等权平均，得到 `Q_SPARC` 和 `Q_TED`。

最终显示分数：

```
score = 100 * Q_SPARC * (0.8 + 0.2 * Q_TED)
```

TED 最多下调主分的 20%，不会把很低的 SPARC 加分成高分。0.8/0.2 是预先指定的工程显示权重，不是论文给出的最优系数。全部参数集中在 `PHASE_SPARC_CONFIG`，没有 episode 特例。

该分数依然是当前数据集内的相对分。70/30 的分档只用于浏览排名；没有绝对合格线、自动剔除规则或低于 30% 的误判率声明。

## 6. 实际限制

事件状态不等于完整动作语义；同一夹爪状态仍可能包含不同子任务。标准 SPARC 使用速度模长，可能漏掉纯方向变化；位置 TED 不评价姿态抖动。自动噪声估计不是独立传感器标定。诊断窗口不影响总分，因此总分不能单独保证检出每个短异常。

当前参数与显示权重并未通过独立质量数据集标定。用户禁止用人工结论验证，本版本不计算合格误拒率或不合格检出率。
